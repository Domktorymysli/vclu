### Lua runtime

- **`VirtualThermostat` keeps a room at its set point with any sensor and any on/off output** - `VirtualThermostat:new("salon", { source = sensor, output = heater, hysteresis = 0.5, persist = true })` switches the output at target ± hysteresis (heating or cooling), only on a crossing. A source that stops changing for `staleAfter` (15 min) or an output on longer than `maxOn` switches the output off and is logged once; after a reload or restart the output starts off. Modes off, set point and holiday; `persist` keeps the set point, mode and state. It has the interface of a Grenton thermostat, so `expose(th, "climate")`, `lib/panel` and `section:thermostat` take it as one ([#63](https://github.com/Domktorymysli/vclu/issues/63)).
