### Dashboards

- **A room from the house model** - `section:area('Salon')` fills a section with a widget for every device `expose()` put in that area, picked by kind as `Panel.area` does: a light, switch or lock a toggle, a dimmer a dimmer, an RGB light the colour widget, a cover a cover, temperature and humidity a status (a thermostat none yet, #64). `kinds` (default light, dimmer, cover, temperature, humidity) and `skip = { path }` choose, lights come first, then covers, then the rest by name in Polish order (Ł right after L, case-insensitive), labels are the `expose()` names and a read-only device's widget is disabled. The section is filled again when something is exposed, unexposed or its options change (values are read live), so devices a plugin exposes later show up without a rebuild, and auth and PIN checks fill nothing; widgets added by hand come after the area's. Widget ids are `area:` + the path with other bytes as `%XX`, so two paths never share an id, and the same after a reload (ids starting with `area:` cannot be given by hand). `dash:floor('Parter', { order, titles, kinds, skip })` adds one section per area on that floor (by name, also in Polish order) with that floor's devices only, empty ones left out; after it a widget needs a new `section()`, which the error says. `expose(obj, type, { dashboard = false })` keeps an object off dashboards and `dashboard = true` adds one of the kinds with a widget even when `kinds` leaves it out (other kinds get none and a warning in the log), separately from `panel`; Home Assistant and HomeKit ignore it. A dashboard with rooms gives whoever opens it control of what is exposed into them later, and the access profiles of MQTT, HomeKit and MCP do not apply to dashboards: the docs recommend `:auth('session')` or `'pin'`. Wrong arguments stop the module with an error naming `section:area` or `dash:floor`, the module's line and what is allowed. `Panel.area` and `Panel.floor` now share the selection with dashboards; `Panel.floor` now shows only the floor's devices when an area name is on two floors ([#92](https://github.com/Domktorymysli/vclu/issues/92)).
