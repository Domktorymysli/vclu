### Plugins

- **`onInit(config, info)` knows the version before an update** - `info.version` is the running version and `info.previousVersion` the one before an update, kept until an init succeeds, so a plugin can move old settings or KV data and retry when that fails.
- **Plugins from the right source** - `@vclu/...` plugins come only from the official repository; another repository listing them is not offered or installed. A repository index may give the sha256 of each plugin file, and vclu then installs only files that match; the official repository always gives them.
- **Updates wait for what the user did not allow** - an action allowed with a confirmation that an update drops waits for the user, also when the files downloaded at install dropped a confirmation the dialog showed; an MQTT filter an update widens waits too, and one it narrows keeps working. Permissions are not changed while the plugin's `plugin.json` cannot be read. The install dialog lists the dashboards the plugin announces. `"api"` in `plugin.json` is written once, in lower case.
- **Short secrets masked too** - a plugin secret under 4 characters (a PIN) is masked in the log where it stands alone; joined to a letter or digit it stays as written (masking is a safety net: a plugin does not log its secrets).
