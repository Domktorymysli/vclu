### Plugins

- **Sign-in from the plugin wizard** - `plugin:login(function(cfg, show, done) ... end)` gives the wizard a "Sign in" button for clouds that sign in through a phone app: `show{qr = text}` shows a QR code vclu draws from the text (up to 1024 bytes), `show{code = "ABCD-1234", url = "https://..."}` a code and a link (OAuth device code, RFC 8628), with an optional `hint`; a later `show` replaces it. `done({token = ...})` saves up to 16 text fields as the plugin's secrets (`plugin:secret(name)`, never shown in the panel or the API, masked in its logs); `done(nil, err)` shows the error. One sign-in per plugin at a time; it ends after 5 minutes, on "Cancel", when the wizard closes or when the plugin stops, and what the plugin calls after that changes nothing. No permission needed; the plugin's HTTP stays under `permissions.internet` ([#288](https://github.com/Domktorymysli/vclu/issues/288)).
