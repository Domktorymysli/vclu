### Plugins

- **TCP to devices on the local network, and telnet** - a new permission `tcp` in `plugin.json` (plugin API 2) gives `plugin:tcpConnect({host, port})`: a client connection with `send`, `onConnect`, `onReceive` and `onClose`, for devices with a TCP protocol of their own (a local Tuya socket, a telnet console). It connects only to local addresses, never to this vclu, and only to the ports the plugin lists in `plugin.json` (`"tcp": {"ports": [23]}`, up to 8); a port of another permission (1234, 69, 502, 1883, 8883) is refused. Installing allows it like `lan`, with the ports shown in the confirmation; the plugins page can limit it to some hosts. `Telnet.wrap(conn)` turns a connection into lines and prompts and refuses the device's option requests; text without a line end goes out as a line past 64 KiB, and a bad prompt pattern is refused when it is set.
