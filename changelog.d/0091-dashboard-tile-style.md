### Dashboards

- **Tiles with an icon in a coloured circle, the name and the state** - every tile shows its icon in a circle coloured by state (on filled, off and no reading grey, a moving cover pulses, a status coloured `danger` or `warning` is an alarm), the name on the first line and the state on the second: "włączone"/"wyłączone", "40 %", "otwarta 70 %" or "zamyka się", a status's value with its unit (Polish decimal comma), a link's host, a chart's latest value, a calendar's next event today. A tap anywhere on a toggle switches it, on the head of a dimmer or a colour light too; a select opens from anywhere on the tile; sliders keep their own row. Header widgets are chips with a small circle, and a toggle or button there now works on a tap. `opts.color` and the dashboard theme still set the colours; tiles, section titles, charts and the calendar follow the theme's text colour, so a light theme (`:theme({ background = ..., cardBg = ..., text = ... })`) is readable. Texts are Polish or English (`?lang=en`, else the browser's language). No dashboard's Lua changes; the definition is pinned by `pkg/lua/dashboard_definition_test.go` ([#91](https://github.com/Domktorymysli/vclu/issues/91)).
