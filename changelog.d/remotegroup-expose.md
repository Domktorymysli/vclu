### Lua runtime

- **`_:byTag(...):expose(type, options)` exposes the group** - the call was forwarded to each object as `obj:expose("switch", {...})`, which takes only options, and failed. The group's own methods (`expose`, `unexpose`, `each`, `filter`, `count`, `cascade`, `saveState`, `restoreState`) are now used, and `group:unexpose()` also removes objects exposed through `expose(obj, ...)` (not an object that took the same path later). `group:expose({ area = ... })` takes options alone, as `obj:expose()` does; without a type each object's own expose type is used, so a thermostat is skipped instead of becoming a switch. `group:saveState()` keeps the states in the group's order (the same id on two CLUs no longer collides) and skips objects without state, such as virtual ones.
