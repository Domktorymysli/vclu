### Home Assistant / MQTT

- Contract change: **only exposed objects are on MQTT** - the registry topics `vclu/<clu>/<component>/<object>/state` and `.../set` are gone; they carried every object in the registry, exposed or not, so what is exposed and its `expose()` options are now the only way onto MQTT. Objects from the Object Manager import are exposed at start as before (`exposeRegistry()`), so their Home Assistant entities, which discovery has always pointed at `vclu/exposed/...`, keep working. A Node-RED flow or a hand-written YAML on the old topics moves to `vclu/exposed/vclu/<component>/<clu>_<object>/...` (lowercase, e.g. `vclu/exposed/vclu/switch/clu220000592_dou0789/set`). Old retained states stay on the broker until cleared (`mosquitto_sub -t 'vclu/+/+/+/state' --remove-retained -W 2`). The undocumented `MqttHandler` class and the unused Go discovery generator (`omparser.GenerateHADiscovery`) are removed with them.
- **`expose(..., { mqtt = false })` keeps commands off too**, as it already did discovery and states.
