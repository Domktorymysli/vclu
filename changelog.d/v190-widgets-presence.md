### MCP

- **Agents are pointed to `VirtualPresence` for a light on motion** - the MCP instructions say so instead of leaving agents to write a `setTimeout` per motion. `vclu_runtime_schema` describes the `chart`, `select` and `image` widgets and how values reach an open page (at once after a state change; `:poll()` only for what no state change shows). The API reference no longer gives `image` a `refreshInterval` option (it is `refresh`, with `height` and `align`) or `select` a function for its options (a list only).
