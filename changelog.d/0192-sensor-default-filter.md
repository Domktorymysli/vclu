### Lua runtime

- Contract change: **imported sensors report only real changes** - a temperature, humidity or light sensor that `exposeRegistry()` exposes (the Object Manager import, not exposed by a module) gets a default `filter`: temperature `{ delta = 0.2, heartbeat = 600 }`, humidity `{ delta = 1, heartbeat = 600 }`, light `{ delta = 5, heartbeat = 600 }`. A reading flipping by one step (25.5/25.6, 0.1/0.2 lx) no longer fills the history, MQTT/Home Assistant, HomeKit and `onChange`; `getValue()` stays raw. Sensors exposed by hand with `expose()` and other types are unchanged. `ExposedObjects:defaults(path, opts)` sets the `filter`, `name` or `area` of one imported object from a module, before it is exposed (after start it changes the exposed object). A `VirtualThermostat` whose source is filtered still counts every raw change as a reading, so it does not go stale. To get every change back: `ExposedObjects:defaults(path, { filter = false })` in a module, or `ExposedObjects:get(path):update({ filter = false })`, or expose the sensor by hand ([#192](https://github.com/Domktorymysli/vclu/issues/192)).
