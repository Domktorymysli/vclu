### Lua runtime

- **`Crypto` and `bit` for modules and plugins** - `Crypto.sha256`, `sha1`, `md5`, `hmac(alg, key, data)`, AES-GCM (`aesGcmEncrypt`/`aesGcmDecrypt`, a 12-byte nonce, the 16-byte tag at the end; a tag that does not match gives `nil, err`), AES-ECB and AES-CBC with `pkcs7` or `none` padding, `Crypto.random(n)` and hex/base64 helpers (`toBase64(s, true)` is base64url without padding; `fromBase64` takes both). Binary data is a plain Lua string. `bit` has LuaJIT BitOp's `band`, `bor`, `bxor`, `bnot`, `lshift`, `rshift`, `arshift` and `tohex`, 32-bit. Both are available in modules, in `vclu_draft_test` and to plugins on API 1 and 2 without a permission; a plugin gets its own copies. Enough to sign cloud API requests (Tuya, eWeLink) in a plugin ([#257](https://github.com/Domktorymysli/vclu/issues/257)).
