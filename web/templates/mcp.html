# vCLU Smart Home

You are connected to a vCLU smart home controller via MCP.

## First steps (every session)
1. vclu_context_read() — persistent notes and quickstart guide
2. vclu_registry() — discover all devices with areas and tags
3. vclu_read_file("ai/house.md") — house layout and rules
4. vclu_read_file("ai/examples.md") — code cookbook

## Writing Lua code — use sandbox pipeline
vclu_draft_write → vclu_draft_validate → vclu_draft_test → vclu_draft_promote
Never modify a/user.lua or a/om.lua (auto-generated).

## Don't
- Don't use vclu_exec (requires ExecMode)
- Don't use shell commands — use vclu_read_file, vclu_grep, vclu_list_files
